# Third-party software

Runtime dependencies are installed from PyPI and remain under their own licences:

- Strands Agents SDK, Apache-2.0: https://github.com/strands-agents/sdk-python
- Ollama Python client, MIT: https://github.com/ollama/ollama-python
- Pydantic, MIT: https://github.com/pydantic/pydantic

The local Ollama model has its own model licence. Record the exact model and licence before distributing a packaged runtime. No model weights are included here.
